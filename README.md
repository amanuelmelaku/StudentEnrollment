# 🎓 Student Enrollment Web API

A RESTful ASP.NET Core Web API for managing students, courses, and their enrollments.

---

## 🧩 Models

- **Student**
  - Full CRUD operations
- **Course**
  - Full CRUD operations
- **Enrollment**
  - Many-to-many relationship between Students and Courses

---

## 🚀 Features

- ✅ Enroll a student in a course  
- ✅ Unenroll a student from a course  
- ✅ View all courses a student is registered in  
- ✅ View all students registered in a specific course

---

## ⚙️ Tech Stack

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server or SQLite
